# Agenda Elayne Psicóloga — PWA

Arquivos prontos para publicar no GitHub Pages.

## Publicação
1. Crie um repositório no GitHub.
2. Envie **todos os arquivos e pastas** desta pasta para a raiz do repositório.
3. Ative **Settings → Pages → Deploy from a branch** e selecione a branch principal e a pasta `/ (root)`.
4. Abra a URL do GitHub Pages no celular. O navegador deverá oferecer a instalação do aplicativo.

O PWA inclui `manifest.webmanifest`, `sw.js`, ícones e cache offline básico.
